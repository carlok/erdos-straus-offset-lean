# Prompt: Small Theorem Miner

```text
We have the following construction, examples, or partial theorem:

[MATHEMATICAL DATA]

Search for a small symbolic theorem around it.

Try these moves in order:

1. Freeze all but one or two parameters.
2. Compare the condition at parameter n with the condition at n + T k.
3. Derive exact difference identities before guessing a period.
4. Separate hypotheses that are preserved automatically from those requiring
   divisibility or positivity.
5. Search for the smallest sufficient period, not merely an obvious period.
6. Turn one valid seed into a parametric family.
7. Attempt the converse and look for a small counterexample.
8. Remove each hypothesis one at a time.
9. Classify equality, minimal, singular, and boundary cases.
10. Identify an invariant explaining successful examples.

For a proposed theorem provide:

- the weakest useful statement;
- exact definitions;
- a complete proof;
- where every assumption is used;
- explicit examples and nonexamples;
- the shortest certificate for an arbitrary instance;
- a counterexample to at least one tempting stronger version.

Do not call the result new. End with a list of distinctive formulas, sequences,
and equivalent terminology suitable for a literature search.
```
